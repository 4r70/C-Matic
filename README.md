# C-Matic: investor demo prototype

Clickable prototype of C-Matic, a CBAM data gateway. One producer, one CBAM dataset, many EU importers.
All data is mocked, seeded and kept in memory. No backend. Emission values are illustrative.

```
npm install
npm run dev      # http://127.0.0.1:5173
npm run build
```

Use **Start tour** in the top bar for the guided demo. **Reset demo** restores the seed state. The Producer / Importer switch jumps sides instantly.
